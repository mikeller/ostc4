# Documentation And Reference Material

This directory preserves upstream and historical OSTC4 documentation, hardware project files, and OpenOCD configuration examples. Keep existing paths stable unless an upstream layout change requires otherwise.

Do not add generated binaries, device flash dumps, or maintained helper scripts here. Store device-specific recovery data outside the repository. Put maintained utilities in `../scripts/` instead.

The `dump-disc.cfg` and `dump-rte.cfg` files are historical upstream OpenOCD configurations. They remain here until they are validated and an upstream-compatible relocation is justified.
